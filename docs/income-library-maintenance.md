# Earning from Nigeria: editorial structure

The hub is `/earning-from-nigeria`. It has nine stable pillar routes:
services, digital-products, teaching, subscriptions, licensing, advertising,
sponsorship, affiliate-referrals and speaking.

The full reviewed drafts live in `content/earning-from-nigeria/01-…09-*.md`.
`scripts/build-income-library.py` builds the hub, the nine article pages,
article downloads, combined Markdown, self-contained reading/print HTML,
deterministic ZIP, catalogue and sitemap entries.

## Add a child article

1. Create the full reviewed Markdown at
   `content/earning-from-nigeria/<pillar>/<child-slug>.md`.
2. Add its `pillar`, `slug`, `title`, `description`, `source` and `date`
   to `CHILDREN` in the builder. The source starts with the title and byline.
3. Run `python scripts/build-income-library.py`. It produces
   `/earning-from-nigeria/<pillar>/<child-slug>.html`, breadcrumbs to the
   pillar, an Article schema, sitemap entry and a link in the parent pillar.
4. Run `python scripts/check-income-library.py` and the existing building-series
   check. Review the new article on mobile and desktop before publishing.

The future exploration prompts are plain text, not links to unfinished pages.
Only completed entries in CHILDREN create published child links. The current
portable collection contains the nine pillars; a later child collection should
be explicitly packaged rather than silently described as part of this edition.

## Parent essay and discovery

The original earning essay remains at its existing URL. Its link to the hub
is generated by `scripts/build-building-series.py`, which also adds the hub
to the How I Build collection. Homepage and New Possibilities provide further
entry points. Existing essays, precision articles and the customer canvas remain.

## Publication scope

These are commercial explorations, not claims of achieved earnings or active
offers. No advertising, checkout, affiliate links, sponsorships or subscriptions
are activated by publishing the articles. Article, CollectionPage and ItemList
metadata describe the published content; they make no unsupported business claims.
