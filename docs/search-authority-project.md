# NaijaOS Search Authority Project
Started: 1 November 2026. Owner: Paul A. Magaji.

## Objective
Earn leading organic rankings and attributable AI citations across the site's strongest subject clusters. Number one is an ambition, not a promised outcome. Measure specific queries, countries, devices and dates; never claim universal category leadership from isolated results.

## Verified starting evidence
Repository main contains robots.txt and sitemap.xml. robots.txt advertised an older naijaos-amber.vercel.app sitemap while sitemap.xml lists naijaos.io URLs. This branch aligns that declaration. Vercel configuration uses cleanUrls with trailingSlash false.
The repository homepage metadata names another Vercel hostname. This is a configuration clue, not proof of deployment behaviour.
Live homepage, robots and sitemap retrieval failed through the research tool on 1 November. Availability, redirects, response headers, indexing, traffic and rankings remain unverified. No Search Console access was established.

## Measurement contract
Maintain a query register with: query, intent, cluster, canonical URL, country/device/language, baseline date, source, impressions, clicks, CTR, average position, observed rank, AI platform/model, prompt, citation URL and observation date.
Unknown is not zero. Search Console average position is not a fixed rank. Do not infer AI citations from general referral traffic.
For a reproducible AI sample, preselect 20 relevant prompts, record platform/model/date and repeat across three independent sessions. Report citation counts and denominator per platform; count only links actually citing NaijaOS. This is a sample, not market share.
Google AI feature traffic is included in Search Console Web reporting; it does not supply a separate complete AI citation scoreboard.

Provisional operational targets: audit all inventoried public URLs; assign one primary page to each selected intent; upgrade five priority pages; publish one tested case. Set traffic/ranking growth targets only after baseline evidence.
Report top-10, top-3 and observed first-place coverage within the selected query set, alongside useful visits and tool completions. Never widen the claim to all searches.

## Publication and evidence gates
Each implementation needs a reviewable diff, relevant checks, preview evidence and production verification. Preserve existing design and content. Recheck current PR/deployment status rather than assuming historic release blockers still apply.
No invented testimonials, results, credentials, partnerships, sources or updated dates. Structured data must match visible content.
The robots correction alone does not prove crawling, indexing or improved rankings.
