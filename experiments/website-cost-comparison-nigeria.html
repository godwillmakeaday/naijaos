What will your business website really cost over two years?

A practical worksheet for comparing a WordPress-led website and a Next.js-on-Vercel implementation using the same scope and your own written quotes.

Evidence status: This is an arithmetic tool, not independent price research. No vendor fees are pre-filled and results are never sent or stored by the tool. It excludes taxes, exchange-rate changes, transaction charges, discounted cash flow and major unforeseen scope changes. This draft is intentionally marked noindex.

How the calculation works

Base cost = one-time build + migration + months × (monthly hosting + monthly tools + maintenance hours × hourly rate). An optional percentage reserve is then added for planning. Quotes must be in one currency and reflect comparable requirements.

The contingency reserve is not a guaranteed expense and is not a verified prediction. Zero is acceptable only when there is genuinely no cost for that item.

How to make your comparison credible

  1. Write one requirements brief covering publishing, design, user accounts, interactive features, speed and support.
  2. Get real quotes covering the same features, usage and support response.
  3. For commercial projects, avoid assuming Vercel's Hobby tier is suitable: its terms restrict it to personal noncommercial use.
  4. Record how editors publish, how data is backed up, and how failures are repaired.
  5. Verify taxes, actual billing currency, ongoing paid tools and vendor contract changes separately.

Provider documentation consulted

  • WordPress roles and capabilities
  • WordPress updates and backups
  • Next.js rendering and navigation documentation
  • Vercel Hobby eligibility and limitations
  • Vercel pricing (published Pro starting rate is USD $20/month, before applicable tax and additional usage)

Documents reviewed 3 November 2026. Pricing can change. Neither the amount of a WordPress implementation nor the full cost of a Next.js project can be determined from a platform's entry-level hosting price.
